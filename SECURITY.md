# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**
(<https://github.com/Rigzar/custom40k-builder/security/advisories/new>). Only the maintainers can read it.

Useful things to include: what you found, the page or request where it happens, the steps to reproduce it, and what an attacker
could do with it. You do not need to include any personal data.

## What is in scope

- The army builder web app (`custom40k-builder.vercel.app`) and the code in this repository, including its serverless functions in `api/`.
- Accounts, saved armies, events, leagues and the Gitfinda board.

Mistakes in the game data (a wrong point cost, a missing rule) are not security issues: please use the in-app bug report form or a normal issue.

## What to expect

We read every report, confirm it, fix it, and then publish the fix. This is a volunteer project, so there is no fixed response time.
